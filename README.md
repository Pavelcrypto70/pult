# Пульт · салон дверей

Операционка для **магазина дверей**: сделки по трём направлениям, обзор со сводкой, задачи шефа, витрина, замеры и монтаж.

Логика продукта: [`docs/LOGIC.md`](docs/LOGIC.md).

## Что внутри

- канбан сделок: продажа / поставка·доставка·монтаж / постгарантийный сервис
- drag карточек и блоков, автопереход по действиям, история
- конструктор блоков, шаблона полей и правил переходов
- создание карточки с выбором блока и полями шаблона
- обзор по живым данным доски (`localStorage`)
- задачи шефа с привязкой к сделке
- витрина, заказы, замеры, монтаж
- админка команды

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123).
