# Пульт · салон дверей

Операционка для **магазина дверей**: сделки по трём направлениям, обзор со сводкой, задачи шефа, витрина, замеры и монтаж.

## Что внутри

- канбан сделок: продажа / поставка·доставка·монтаж / постгарантийный сервис
- обзор с общим отчётом по данным
- задачи: выбор сотрудника + новая задача
- витрина, заказы, замеры, монтаж
- админка команды

## Запуск

```bash
npm install
npm run dev
```

Демо: [https://pavelcrypto70.github.io/pult/](https://pavelcrypto70.github.io/pult/)
