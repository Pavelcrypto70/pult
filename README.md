# Пульт · салон дверей

Операционка для **магазина дверей**: сделки по трём направлениям, витрина, замеры, конфигуратор, монтаж и общий отчёт.

## Что внутри

- канбан сделок: продажа / поставка·доставка·монтаж / постгарантийный сервис
- общий отчёт по данным
- витрина, заказы, замеры, конфигуратор, монтаж
- клиенты, задачи, админка команды

Конструктор компаний и multi-tenant убраны — продукт заточен только под салон дверей.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- статическая сборка для GitHub Pages

## Запуск

```bash
npm install
npm run dev
```
