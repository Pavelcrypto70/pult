# Пульт

Упрощённый аналог Битрикса для студий и малого бизнеса — с премиальной вертикалью **магазина дверей**.

## Зачем

Битрикс и тяжёлые CRM избыточны для команд 5–30 человек. Notion/таблицы превращаются в кашу. **Пульт** — операционный слой с топовым интерфейсом и узким набором модулей. Для салона дверей — полный цикл от витрины до монтажа.

## Что уже есть

- лендинг продукта
- рабочий кабинет со shell-навигацией
- обзор, клиенты, воронка, задачи
- админка: команда, права, интеграции, журнал
- конструктор компаний + пресет **Atelier Doors**
- салон дверей: витрина, заказы, замеры, конфигуратор, монтаж

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- клиентский MVP на mock-данных

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Салон дверей

| Экран | Путь |
|---|---|
| Витрина коллекций | `/app/doors` |
| Канбан заказов | `/app/doors/orders` |
| Замеры проёмов | `/app/doors/measurements` |
| Конфигуратор + смета | `/app/doors/configurator` |
| Монтаж и гарантия | `/app/doors/install` |

В конструкторе компании: кнопка **«Пресет: салон дверей»** подключает модули каталога, конфигуратора, замеров, заказов, монтажа и регламентные страницы.

## Карта большого проекта

| Модуль | Статус | Следующий шаг |
|---|---|---|
| Клиенты | UI + mock | CRUD, карточка, таймлайн |
| Воронка | UI + mock | drag-and-drop, суммы, фильтры |
| Задачи | UI + mock | назначения, статусы, дедлайны |
| Салон дверей | UI + mock | PDF КП, склад, акты |
| Админка | UI + mock | инвайты, RBAC, API-ключи |
| Auth / multi-tenant | planned | организации и роли |
| Интеграции | planned | Telegram, почта, webhooks |

## Принципы

1. Не копировать Битрикс списком модулей.
2. Админка — first-class продукт.
3. Сценарий дня важнее конструктора «настрой всё сам».
4. Визуал и скорость интерфейса — часть позиционирования.
5. Вертикаль дверей — полный цикл салона, не «ещё один модуль каталога».
