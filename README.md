# Пульт · салон дверей

Операционка для **магазина дверей**: сделки по трём направлениям, обзор, задачи шефа, витрина, замеры и монтаж.

- Логика продукта: [`docs/LOGIC.md`](docs/LOGIC.md)
- Заметки обсуждений, аналоги CRM, инвентарь канбана, варианты потоков: [`docs/NOTES.md`](docs/NOTES.md)

## Вход

Демо-админ:

| | |
|---|---|
| Логин | `admin` |
| Пароль | `pult-admin` |

После входа открывается обзор и канбан. Кнопка «Выйти» — внизу сайдбара.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123) → **Войти**.

## Что внутри

- канбан: drag карточек и блоков, действия с автопереходом, конструктор
- вход по аккаунту (демо)
- задачи с привязкой к сделке
- витрина, заказы, замеры, монтаж
- админка команды

## Карта экранов

| Экран | Путь |
|---|---|
| Вход | `/login` |
| Обзор | `/app` |
| Сделки | `/app/pipeline` — рабочий канбан |
| Воронка | временно скрыта из меню (`/app/funnel` остаётся в коде) |
| Архив | `/app/archive` |
| Задачи | `/app/tasks` |
| Витрина / каталог | временно скрыты из меню |
